Sou desenvolvedor full stack júnior e estudante de Sistemas de Informação, em Ituverava (SP). Gosto de entender **como as coisas funcionam por baixo**, do que o usuário vê na tela até o banco de dados.

Estou em busca de um **estágio ou vaga júnior** onde eu possa aprender com um time e entregar software que resolva problemas reais.
